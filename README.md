
# ⛓️ BlockFusion

A lightweight blockchain implementation built with Python and Flask to demonstrate core blockchain concepts such as blocks, transactions, Proof of Work, hashing, and consensus.

## Features

- Block creation and management
- Transaction handling
- SHA-256 hashing
- Proof of Work (PoW)
- Node registration
- Consensus algorithm
- REST API endpoints
- Unit testing

## Tech Stack

- Python
- Flask
- Requests
- SHA-256 Cryptography
